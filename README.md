# Kareem — About Me

A five-slide, responsive English personal introduction presentation with a dark navy and blue design.

## Slides
1. All About Me
2. Who Am I?
3. My Interests
4. Programming Skills
5. Thank You

## Controls
- **Right Arrow / Space / Page Down:** Next slide
- **Left Arrow / Page Up:** Previous slide
- **Home / End:** First or last slide
- **F:** Toggle fullscreen
- **Touch:** Swipe left or right
- Use the bottom dots to jump to a slide.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

No build tools or installation are required.
